# 競合ベンチマーク

        ## 比較対象

        - GitBook: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Notion: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Microsoft Learn: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。
- Google Docs: 採用基準は入力負荷、記録粒度、証跡性、ローカル完結性。

        ## 採用する基準

        - 入力負荷が低い。
        - 次アクションが明確。
        - ローカルまたは閉域で検証できる。
        - docs と release evidence から状態を追える。

        ## 差別化

        操作手順を学習コンテンツ化し、確認、練習、完了証跡を残すガイドに絞り、汎用ノートや大型サービスよりも閉域アルファの検証可能性を優先します。
